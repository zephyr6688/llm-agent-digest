## 发布流程

1. **终审**：通读全文，改掉不像你口吻的句子，核对数字与链接；
2. **专栏文章**：直接复制粘贴（知乎编辑器支持 Markdown），标题保留工程化风格，发布时勾选"专栏"并同步到相关话题（人工智能 / 程序员 / 大语言模型）；
3. **回答**：按选题池的绑定方法找问题 → 把草稿前 3 行按目标问题微调（呼应提问者语境）→ 发布；
4. **纪律**：每篇注明"首发于公众号《Agent 工程周报》"（专栏版已有）；引用的每条内容保留原文链接；点评为原创部分；
5. **数据回填**：发布 48h 后把赞同数/评论数记到本文件底部。
